**私有仓库，请勿外传。**

## 下载

| 文件 | 说明 |
| --- | --- |

## 版本

- **v1.6.0**（2026-10-10）
  - 界面简约现代化：扁平卡片、细边框、去花哨渐变
  - 去掉「待补密码」提醒，删除「今日分小时销售」模块
  - 大类模块合并为「大类销售 / 销售与库存对照」（剩余库存并入对照，含存销比）
  - 销售趋势只保留 **本周 / 本月 / 本年**，默认本周；窗口内按天补 0，修掉首柱异常
  - 门店选择：选中的门店自动排到最左
  - 季节默认只统计销售（秒级出表），库存按需点「含库存统计」
  - **取数安全**：限速降到 12 次/分钟；命中厂家限流「0002」或登录异常即进入保护期
    （30s→1min→2min→5min 指数退避，期间不再发任何请求，不影响门店收银）
